# راه‌اندازی سرور روی همروش

سرور یک سرویس Docker است: API بازی + فایل SQLite روی دیسک. دیتابیس یا Redis جدا لازم نیست.

## ۱. ساخت اپ
- در همروش یک اپ از نوع Docker/Git بساز و این ریپو را وصل کن؛ `Dockerfile` در ریشهٔ ریپو است (یا image را خودت با `docker build -t chakachak-server .` بساز و push کن).
- پورت داخلی: `8080`. مسیر سلامت: `/health`.
- **فقط یک نمونه (replica = 1)** اجرا کن؛ SQLite یک نویسنده دارد.

## ۲. دیسک ماندگار (حیاتی)
یک دیسک (Volume) به مسیر **`/data`** وصل کن. فایل `chakachak.db` و پوشهٔ `backups/` آنجاست. بدون دیسک، با هر دیپلوی همهٔ حساب‌ها پاک می‌شوند.

## ۳. متغیرهای محیطی
| نام | مقدار |
|---|---|
| `SECRET` | رشتهٔ تصادفی حداقل ۳۲ کاراکتر (برای هش شماره‌ها). **هرگز عوضش نکن**؛ وگرنه شماره‌های ثبت‌شده پیدا نمی‌شوند. |
| `SMS_PROVIDER` | `kavenegar` (در غیر این صورت کدها فقط در لاگ چاپ می‌شوند) |
| `KAVENEGAR_KEY` | کلید API کاوه‌نگار |
| `KAVENEGAR_TEMPLATE` | نام الگوی «verify lookup» در پنل کاوه‌نگار (با یک توکن `%token`) |
| `BACKUP_HOURS` | فاصلهٔ پشتیبان‌گیری (پیش‌فرض ۶) |
| `DEV_TOOLS` | فقط برای سرور تست: `1` ابزار تست (سکه/الماس مجانی) را فعال می‌کند. در سرور اصلی نگذار. |
| `TEST_OTP` | فقط سرور تست بدون پیامک: کد ثابت ورود |

## ۴. دامنه
یک دامنه/زیردامنه (مثلاً `api.chakachak.ir`) با HTTPS به اپ وصل کن. اپ اندروید با `VITE_API_URL=https://api.chakachak.ir` ساخته می‌شود.

## ۵. پشتیبان
سرور هر چند ساعت یک نسخهٔ کامل در `/data/backups` می‌سازد (۱۴ نسخهٔ آخر). این پوشه را دوره‌ای بیرون از سرور هم کپی کن (فضای ابری S3 همروش/آروان). برای بازگردانی: سرویس را متوقف کن، فایل پشتیبان را جای `/data/chakachak.db` بگذار و دوباره اجرا کن.

## ۶. تنظیم بالانس از راه دور
یک ردیف در جدول `remote_config` با `active = 1` و JSON تغییرات (فقط کلیدهایی که عوض می‌شوند، مثلاً `{"game":{"ECON":{"skipSecPerGem":600}}}`) بالانس را بدون آپدیت اپ عوض می‌کند (حداکثر یک دقیقه تأخیر). پنل مدیریت در مرحلهٔ ۷ این کار را ساده می‌کند.
